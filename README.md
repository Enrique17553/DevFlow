# DevFlow

> Plataforma web de gestão desenvolvida com Python e tecnologias web.

## Sobre

O DevFlow é um projeto full-stack criado para demonstrar desenvolvimento de aplicações web modernas.

A aplicação possui um dashboard conectado a uma API desenvolvida em Python/Flask.

## Tecnologias

* Python
* Flask
* HTML5
* CSS3
* JavaScript
* REST API

## Funcionalidades

* Dashboard de métricas
* Cadastro de clientes
* Pesquisa de clientes
* Gerenciamento de pedidos
* Cálculo automático de faturamento
* API REST
* Interface responsiva
* Design adaptado para desktop e celular

## Como executar

Clone o projeto:

```bash
git clone SEU_LINK_DO_GITHUB
cd devflow
```

## Instale as dependências:

```bash
pip install -r requirements.txt
```

## Execute:

```bash
python app.py
```

## Depois abra no navegador:

```text
http://127.0.0.1:5000
```

## Endpoints da API

```text
GET /api/dashboard
GET /api/clientes
GET /api/clientes?busca=Ana
GET /api/pedidos
POST /api/clientes
```
